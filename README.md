🔗 **[Ver la web en vivo (Demo)](https://alejandrolara.vercel.app/)**

---

## ✨ Características Principales

- 🧊 **Estética Glassmorphism:** Interfaz limpia basada en tarjetas de cristal translúcidas.
- 📐 **Ecosistema Matemático Vivo:** Fondo animado con Canvas 2D que simula nodos, conexiones y ecuaciones flotantes.
- 🚀 **Animaciones Fluidas:** Transiciones de scroll, efectos de aparición (pop) y desplazamientos laterales manejados mediante **Framer Motion** y **GSAP**.
- 📱 **Diseño 100% Responsivo:** Adaptado perfectamente a móviles, tablets y monitores de escritorio.
- ✉️ **Contacto sin Servidor:** Integración directa con **Formspree** para el envío de correos sin necesidad de un backend propio.
- 🎓 **Línea de Tiempo Dinámica:** Representación visual del itinerario de 5 años del Doble Grado en Informática y Matemáticas.

---

## 🛠️ Tecnologías Utilizadas

*   **Frontend Framework:** React.js (Componentes Funcionales y Hooks)
*   **Build Tool:** Vite (Para un empaquetado y HMR ultra rápido)
*   **Estilos:** Tailwind CSS (Utilidad-primero)
*   **Animaciones:** Framer Motion & GSAP
*   **Iconografía:** React Icons (FontAwesome & SimpleIcons)
*   **Gestión de Formularios:** Formspree.io

## 🚀 Instalación y Despliegue Local

Si quieres clonar este repositorio y ejecutarlo en tu máquina local, sigue estos pasos:

1. **Clona el repositorio:**
   ```bash
   git clone [https://github.com/AlexLL8416/Portfolio.git](https://github.com/AlexLL8416/Portfolio.git)
   ```

2. **Accede al directorio del proyecto:**
   ```bash
   cd tu-repositorio
   ```

3. **Instala las dependencias:**
   ```bash
   npm install
   ```

4. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

5. Abre tu navegador y visita `http://localhost:5173/`

## 📂 Estructura del Proyecto

La arquitectura del código está basada en componentes modulares para facilitar la escalabilidad:

```text
src/
├── assets/                  # Imágenes, PDFs y recursos estáticos
├── components/
│   ├── layout/              # Navbar, Footer (Elementos globales)
│   ├── sections/            # Componentes principales (Hero, Skills, Projects, Education, Contact)
│   └── ui/                  # Componentes reutilizables (CanvasBackground, etc.)
├── App.jsx                  # Ensamblaje de la vista principal
├── main.jsx                 # Punto de entrada de React
└── index.css                # Estilos globales y variables de Tailwind
```
